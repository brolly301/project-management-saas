# project-management-saas
Production-grade project management SaaS built to explore modern full-stack architecture using React, FastAPI, PostgreSQL, Docker, Redis, Celery, AWS and AI-powered productivity features.

## Why I'm Building This

I'm building this project to deepen my understanding of modern backend engineering beyond traditional CRUD applications. The goal is to learn how production software is designed, deployed and maintained while creating a project that demonstrates real-world software engineering practices.
